## 2. 畫面與流程

```
打開 App ─→ 設定頁 ──按「開始」──→ 計時頁 ──全部跑完──→ 完成畫面 ──點一下──→ 設定頁
                │                     │ 點一下＝暫停／繼續
                └─ ☰ 常用設定抽屜      └ 長按 1 秒＝結束 → 設定頁（不顯示完成畫面）
```

- 只支援直向；全頁關閉長按選字、放大鏡與系統選單。

### 2.1 設定頁（排版同 `design/settings.html`，由上到下）
1. 頂列：左「☰ 設定名稱」（打開常用設定抽屜）、右「聲音開關」。
2. 總時間（大字，例 `25:10`；滿 60 分鐘顯示 `1:05:30`）。
3. **「開始」按鈕**（在總時間正下方）。
4. 六個設定列：名稱、−、數值、＋。
- 打開 App 時帶入**上一次用的設定**；第一次使用帶入 Tabata。
- 任一數字被改過，頂列名稱變成「自訂」。

### 2.2 計時頁
- 第一行小字：左＝目前位置，右＝總剩餘（例「12:40」）。
  - 目前位置：準備時「共 3 組 × 8 回」；運動／休息時「第 2 組 · 3/8 回」；組間休息時「第 1 組完成」。
- 第二行（只在螢幕常亮開不起來時出現）：小字「⚠ 螢幕可能會自動變暗」。
- 中間：圓環＋階段名稱＋**剩餘秒數（最大的元素）**。
- 下方小字：「下一段：休息 20 秒」（秒數 0 被略過的段落不算）；沒有下一段時顯示「最後一段」。
- 暫停時蓋一層半透明，顯示「已暫停／點一下繼續／長按 1 秒結束」，以及小字「螢幕常亮：已開啟／未開啟」。

### 2.3 完成畫面
- 「訓練完成」＋本次內容（例「3 組 × 8 回 · 25 分 10 秒」）＋「點一下回到設定」。
- 出現後**前 1 秒不接受點擊**，避免剛好在點螢幕時誤跳走。

## 3. 設定欄位

| 欄位 | 最小 | 最大 | 每按一下 | 備註 |
|---|---|---|---|---|
| 準備 | 0 | 60 秒 | 5 秒 | 0＝不準備，直接開始運動 |
| 運動 | 5 | 600 秒 | 5 秒 | |
| 休息 | 0 | 600 秒 | 5 秒 | 回合＝1 時變淡（用不到） |
| 回合 | 1 | 50 | 1 | |
| 組數 | 1 | 20 | 1 | |
| 組間休息 | 0 | 600 秒 | 15 秒 | 組數＝1 時變淡（用不到） |

- 秒數顯示：未滿 60 顯示「20 秒」，60 以上顯示「1:30」。
- 到上下限時該側按鈕變灰不能按。變淡的欄位仍可調整。
- 按住按鈕：0.4 秒後開始連續加減，每 0.08 秒一次，到上下限自動停。
- **總時間** ＝ 準備 ＋ 組數 ×（回合 × 運動 ＋（回合−1）× 休息）＋（組數−1）× 組間休息。
  驗算（Python 重算過）：Tabata 10＋1×(8×20＋7×10)＝240 秒＝4:00；HIIT 10＋1×(4×30＋3×30)＝220 秒＝3:40。

## 4. 常用設定（底部抽屜）

- 內建：Tabata（準備 10／運動 20／休息 10／8 回／1 組／組間 60）、HIIT（10／30／30／4 回／1 組／60）。內建的不能刪、不能覆蓋。
- 清單每列：名稱＋摘要（「40/20 秒 × 8 回 × 3 組 · 25 分 10 秒」）；點一下＝套用並關閉抽屜。
- 自己存的設定有 ✕，按下先跳確認「刪除『晨練』？」才刪。
- 儲存：輸入名稱（去頭尾空白後 1～12 字）→ 儲存。
  - 名稱和自己存的設定重複 → 詢問「要用目前的數字覆蓋『晨練』嗎？」，確定才覆蓋。
  - 名稱和內建設定重複 → 提示「這是內建名稱，請換一個」。
- 關閉抽屜：點背景、或套用任一設定。

## 5. 計時引擎

### 5.1 段落表
按「開始」時依設定產生段落清單，例如 2 組 × 2 回：
準備 → 運動 → 休息 → 運動 → **組間休息** → 運動 → 休息 → 運動 → 完成。
- 每組最後一回合的休息由組間休息取代；最後一組最後一回合後直接完成。
- **秒數為 0 的段落直接略過**。例：休息設 0 → 運動接運動，每次進入新的運動段**照樣**長嗶＋「開始運動」，讓你知道換回合了。

### 5.2 用真實時間計算（關鍵）
- 開始時記下開始時刻；每一格畫面都用「現在時間 − 開始時間 − 暫停累計」算出目前在第幾段、還剩幾毫秒。
- **不是**每秒減 1：所以手機卡頓、切 App、鎖定回來，進度都是對的。
- 畫面更新用 `requestAnimationFrame`；數字顯示取「剩餘秒數無條件進位」（剩 2.3 秒顯示 3）。

### 5.3 聲音觸發規則
- 進入新段落時：先停掉所有還沒播完的聲音 → 長嗶 → 語音。
- 「三／二／一」「還剩十秒」：在**畫面數字變成 3／2／1／10 的那一格**觸發，每個數字每段只播一次。
- 暫停：立刻停止正在播的嗶聲與語音，也取消排隊中的語音。繼續後照常：例如暫停在顯示 4，繼續後跳到 3 就播「三」。
- 從背景回來（見 5.4）：把「已播到哪」直接設成目前狀態，**不補播**任何聲音，下一個數字變化才開始播。

### 5.4 切 App／鎖定再回來
- 回來時依真實時間跳到正確的段落與秒數，不補播離開期間錯過的聲音。
- 若離開期間整場已經跑完 → 直接顯示完成畫面（不播「訓練完成」）。
- 回來時重新開啟螢幕常亮，並重新啟動音效功能（iPhone 切回來時音效可能被暫停）。

### 5.5 暫停與結束（點一下 vs 長按）
- 計時頁任何地方，手指按下後：
  - **0.3 秒內放開＝點一下** → 切換暫停／繼續（暫停中與跑動中都一樣）。
  - **按住超過 0.3 秒** → 圓環外圍出現一圈白色細線，在接下來 0.7 秒內畫滿一圈（總共 1 秒）。
    - 畫滿前放開 → 取消，什麼都不變（不暫停、不結束）。
    - 畫滿 → 停止計時與聲音、釋放螢幕常亮、回到設定頁。
  - **手指移動超過 16 點** → 不算點一下也不算長按（長按提示立刻消失）；若符合 §14.3 的滑動條件就換風格。
- 暫停時時間停止、圓環停住。

## 6. 聲音

### 6.1 播放時機
| 時機 | 嗶聲 | 語音 |
|---|---|---|
| 進入準備 | 長嗶 | 準備 |
| 進入運動 | 長嗶 | 開始運動 |
| 進入休息 | 長嗶 | 休息 |
| 進入組間休息 | 長嗶 | 組間休息 |
| 運動段剩 10 秒（該段 ≥ 20 秒才播） | — | 還剩十秒 |
| 每段剩 3、2、1 秒（該段 **≥ 8 秒**才播） | — | 三／二／一 |
| 全部結束 | 長嗶 | 訓練完成 |

- **≥ 8 秒的理由**：段落開頭「長嗶 0.5 秒＋語音約 1.5 秒」約 2 秒講完；8 秒段落的「三」在第 5 秒，中間留足空檔，不會互相蓋掉。
- **長嗶**：880 Hz、0.5 秒，用網頁內建的音效功能（Web Audio）即時產生，不需要音效檔；嗶聲結束後才講語音。
- **語音**：系統語音，語言 zh-TW。手機的語音清單要等載入完成才拿得到，載入完成後優先挑台灣中文語音，找不到就用系統預設中文。

### 6.2 iPhone 規則
- iPhone 規定聲音要由「點擊」開啟：在按「開始」的那一下同時開啟嗶聲與語音，之後整場都能播。
- **靜音鍵**：語音已實測不受影響；嗶聲**還沒實測**，可能會被靜音鍵擋掉。
  - 原本打算宣告成「播放類」聲音繞過靜音鍵，但審查發現這會**打斷你自己在放的音樂**（Spotify 等），所以 v1 不這樣做。
  - 結果：靜音鍵開著時，可能只剩語音、沒有嗶聲；語音仍會照常提示。若實測後你寧可要嗶聲、不在意音樂被打斷，再改回來。
- 聲音開關關閉時：嗶聲與語音都不播，畫面照常。

## 7. 螢幕常亮
- 按「開始」時開啟，訓練結束或長按結束時關閉。
- 從別的 App 回來、計時還在跑 → 自動重新開啟。
- 狀態顯示：開啟失敗時計時頁常駐小提示（2.2 第二行）；暫停畫面一律顯示「已開啟／未開啟」。需要 iOS 18.4 以上（從主畫面開啟時）。

## 8. 儲存（存在手機的瀏覽器裡）

| 存什麼 | 何時存 |
|---|---|
| 上一次的六個數字＋設定名稱 | 按「開始」時 |
| 自己存的常用設定 | 儲存／覆蓋／刪除時 |
| 聲音開關 | 切換時 |

- 讀回來的資料一律檢查：數字超出範圍就拉回範圍內、格式壞掉就改用 Tabata，不讓 App 打不開。
- 儲存失敗（例：私密瀏覽）不報錯，只是下次不會記得。
- 注意：刪除主畫面圖示會一起清掉這些資料（iPhone 的規定）。

## 9. PWA 與離線
- `manifest`：名稱「間歇計時」、全螢幕（standalone）、直向、深色底 `#0b0b0f`、圖示 180／512。
  - iPhone 會忽略「鎖直向」設定：手機橫放時畫面仍會轉向（版面不會壞）。要固定直向，請在控制中心開「直向鎖定」。
- `sw.js`：第一次開啟時把第 1 節的檔案全部存起來，之後**沒網路也能用**。
- 更新：每次改版 `sw.js` 的版本號加一，新版下載後立即接手、舊快取自動清掉。實際上使用者**可能要關掉 App 重開一到兩次**才看到新版。

## 10. 視覺規格（B 圓環）

### 10.1 階段顏色
| 階段 | 顏色 |
|---|---|
| 準備 | `#fbbf24` 黃 |
| 運動 | `#fb7185` 紅粉 |
| 休息 | `#34d399` 綠 |
| 組間休息 | `#818cf8` 紫 |

- 底色 `#0b0b0f`；文字 `#f5f5f5`；次要文字 `#a1a1aa`；關閉狀態圖示 `#71717a`。
- **遠看分辨階段**（需求 3.4）：背景光暈比樣品更強——不透明度由 0.22 提高到約 0.45，並擴大範圍，讓整個畫面明顯染上階段色。
- 換階段時光暈顏色要**平滑**過渡 0.6 秒（樣品是瞬間跳色，正式版修正）。

### 10.2 尺寸（遠看優先；圓環線寬以圓環直徑 100 為單位）
| 元素 | 樣品 | 正式版 |
|---|---|---|
| 剩餘秒數 | min(44vw, 30vh)，字重 200 | **min(56vw, 36vh)，字重 300**（加大加粗） |
| 剩餘秒數顯示為「1:30」「10:00」時 | — | B：字級乘 0.6，確保在圓環內；A、C：取「寬度上限（10:00 放得下）」與「高度上限（同兩位數）」較小者，橫放時自動放大 |
| 階段名稱 | 26～40px | 28～40px，字距縮小，「組間休息」四字不碰圓環 |
| 圓環直徑 | min(92vw, 60vh) | min(94vw, 62vh) |
| 圓環線寬 | 3，最後 3 秒 7 | 4，最後 3 秒 7 |
| 長按結束的白色細線 | — | 在圓環外側、線寬 1.5 |
| 上下小字 | 18px | 18px |

- **最後 3 秒數字保持白色**（只有圓環變粗），確保在強光暈上仍清楚；這點和樣品不同。

### 10.3 動態效果
| 效果 | 時間 | 曲線 |
|---|---|---|
| 圓環隨時間縮短 | 連續 | 線性（代表時間，必須等速） |
| 數字每秒向上捲動 | 0.45 秒 | (0.4, 0, 0.2, 1) |
| 換階段：顏色轉換、名稱滑入 | 0.5～0.6 秒 | (0.4, 0, 0.2, 1) |
| 最後 3 秒：圓環變粗 | 0.3 秒 | (0.4, 0, 0.2, 1) |
| 背景光暈呼吸 | 計時頁 4 秒、設定頁 5 秒來回 | 緩入緩出 |
| 設定數字變動、按鈕按下 | 0.12～0.25 秒 | (0.4, 0, 0.2, 1) |
| 常用設定抽屜滑出 | 0.4 秒 | (0.4, 0, 0.2, 1) |

- 會「移動」的動畫一律只動位置、大小、透明度；顏色與圓環線寬只做短暫過渡。
- 手機若開啟「減少動態效果」：關掉捲動、呼吸、滑入，只保留圓環與顏色變化。

## 11. 無障礙
- 所有按鈕可被 VoiceOver 讀出（例：「運動增加」「聲音，開啟」）；可按範圍至少 44×44 點。
- 計時中只在換階段時朗讀階段名稱，不逐秒朗讀，避免干擾。
- 文字與底色對比符合 WCAG AA（大字 ≥ 3:1、小字 ≥ 4.5:1），完成後用工具實測。

## 13. 與需求文件不同之處（請確認）
1. **用不到的欄位改「變淡」而不是「隱藏」**（需求 3.1 寫隱藏）：隱藏會讓下面的欄位跳上跳下，變淡位置不動，比較好按。休息欄位在回合＝1 時也比照辦理。
2. **計時頁底色維持深色**，用加強的階段色光暈區分階段（需求 3.4 寫「整個畫面的顏色代表階段」）：這是 B 風格的前提；若實機 3 公尺外分不清，再改成整片底色換色。
3. **結束採長按 1 秒**，不另外跳確認視窗（需求 3.2 寫長按或二次確認，擇一）。
4. **三二一只在 8 秒以上的段落播**（需求寫每段都播）：短段落會和開頭語音疊在一起。
5. **嗶聲也用在「進入準備」和「訓練完成」**（需求寫只在階段切換）：讓開始與結束有明確的聲音標記。
6. **螢幕常亮的狀態**：平常只在失敗時提示，暫停畫面才顯示「已開啟／未開啟」（需求寫畫面上顯示有沒有成功）：避免訓練中多一個常駐圖示分散注意。
7. **完成畫面用「點一下回到設定」**取代樣品中的按鈕：流汗的手不用找按鈕，和暫停的操作一致。

## 14. 倒數畫面風格切換（v0.3 新增）

### 14.1 三種風格
| 風格 | 進度怎麼看 | 數字 | 換階段 | 最後 3 秒 |
|---|---|---|---|---|
| **A 液面** | 整個畫面是一杯水，水位隨時間下降，頂端波浪流動 | 白色粗體、最大 | 標籤與數字由下往上浮出 | 數字每秒跳一下 |
| **B 圓環**（預設） | 圓環縮短（現行版本） | 白色細體 | 光暈換色、標籤滑入 | 圓環變粗 |
| **C 彈跳** | 畫面底部一條進度條（原樣品沒有，正式版補上） | 深色圓體粗字 | 新顏色從中心圓形擴散 | 數字放大＋每秒擴散一圈波紋 |

- **階段顏色三種風格統一**（黃＝準備、粉紅＝運動、綠＝休息、紫＝組間休息），每種風格只調整深淺以確保文字清楚：A 的水用較深的同色、背景用更深的同色；C 的底色用原色、文字用極深的同色。
- 三種風格共用：計時、聲音、上方位置與總剩餘、下一段提示、暫停畫面、常亮提示、完成畫面（教練＋彩帶）。
- 數字置中修正（非等寬數字）三種風格都套用。
- 設定頁不換，維持 B 的深色風格。

### 14.2 長按結束的提示
- B：圓環外側畫一圈白線（現行）。
- A、C：沿著螢幕邊緣畫一圈圓角外框（A 白色、C 深色），1 秒內畫滿。

### 14.3 左右滑動切換
- 條件：手指移動超過 16 點才開始判定（容許抖動）；橫向移動 **≥ 60 點**、且橫向距離是直向的 1.5 倍以上。
- 向左滑＝下一個（A→B→C→A），向右滑＝上一個。
- **從螢幕左右邊緣 20 點內開始的滑動不處理**，留給 iPhone 系統手勢（返回上一頁等）。
- 計時中、暫停中都可以滑；**換風格不影響時間與聲音**，新風格立即顯示目前的秒數、進度、階段顏色。
- 新畫面從滑動方向推入（0.35 秒）；畫面上方短暫顯示「圓環 ○ ● ○」約 1.2 秒。
- 暫停畫面加一行小字「左右滑動可換風格」。
- 鍵盤替代：左右方向鍵。
- App 記住最後使用的風格；第一次使用為 B。

### 14.4 驗收
- [ ] 三種風格在每個階段、最後 3 秒、暫停、長按時畫面正確，數字置中。
- [ ] 點一下仍是暫停；手指滑 30 點放開不換風格也不暫停；滑 80 點換風格；從邊緣 10 點處開始滑不換。
- [ ] 換風格時剩餘時間不變、聲音序列與不換時相同。
- [ ] 重開 App 後保留上次的風格。
