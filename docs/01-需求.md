# 間歇訓練計時器｜需求文件 v0.1（2026-11-23，待 LOLO 確認）

## 1. 目的
- **主要**：一個手機用的間歇訓練計時器，設定簡單、操作直覺、不看螢幕也知道進度。
- **次要（實驗目的）**：嘗試用「有動態效果的網頁」做出像原生 App 的質感與手感。

## 2. 使用情境
- 手機放地上或架子上，**人在 1～3 公尺外**看螢幕、聽語音。
- 主要裝置：**iPhone（Safari）**。
- 從主畫面圖示開啟（PWA），全螢幕、沒有瀏覽器網址列。

## 3. 功能需求

### 3.1 訓練結構（四個數字＋兩個休息）
| 設定項 | 說明 | 範例 |
|---|---|---|
| 準備時間 | 按開始後的緩衝，讓你站到位 | 10 秒 |
| 運動時間 | 每回合運動秒數 | 40 秒 |
| 休息時間 | 回合間休息 | 20 秒 |
| 回合數 | 每組幾回合 | 8 回 |
| 組數 | 共幾組 | 3 組 |
| 組間休息 | 組與組之間的長休息 | 60 秒 |

- 流程：準備 → (運動 → 休息) × 回合 → 組間休息 → 下一組 … → 完成。
- **每組最後一回合的「休息」由組間休息取代**；最後一組結束直接完成，不再休息。
- 設定畫面要顯示**總時長**（例：共 26 分 40 秒），讓你一眼知道要練多久。
- 組數設為 1 時，「組間休息」欄位自動隱藏（等於單純間歇）。

### 3.2 執行中操作（只留最必要的）
- **暫停／繼續**：點螢幕任何地方都可以（流汗的手不用找按鈕）。
- **結束**：需長按或二次確認，避免誤觸中斷整場訓練。
- **跳過這一段**：例如休息想提早開始。（待確認是否需要，見第 6 節）

### 3.3 語音提示（純中文語音，不用嗶聲）
| 時機 | 語音內容 |
|---|---|
| 準備開始 | 「準備」 |
| 進入運動 | 「開始運動」 |
| 運動中剩 10 秒 | 「還剩十秒」（運動段 ≥ 20 秒才報，避免太吵） |
| 進入休息 | 「休息」 |
| 進入組間休息 | 「組間休息」 |
| 每段最後 3 秒 | 「三、二、一」 |
| 全部結束 | 「訓練完成」 |

- 設定頁要有**語音開關**（在公共場所可關掉）。

### 3.4 畫面需求（遠看優先）
- 剩餘秒數**超大字**，佔螢幕主體。
- **整個畫面的顏色代表階段**：運動、休息、組間休息、準備各一色，3 公尺外瞄一眼就分得出來。
- 次要資訊（第幾組第幾回）放小字，不搶主角。
- 動態效果：階段切換的轉場、倒數的進度動畫——要有質感，但**不能影響數字的可讀性**。

### 3.5 像 App 的程度
- **PWA**：可「加入主畫面」，有自己的圖示、全螢幕開啟、**離線可用**。
- 訓練中**螢幕不自動熄滅**。
- 記住上次的設定（下次打開就是上次的數字）。

## 4. 不做的事（刻意排除，保持簡單）
- 不做帳號、雲端同步、訓練紀錄統計。
- 不做多段自訂課表（每段自己命名）。
- 不做多組常用設定的儲存（只記上一次）。
- 不做嗶聲、背景音樂、震動。

## 5. 技術限制與風險（iPhone 特有，需實機驗證）
| 風險 | 影響 | 對策 |
|---|---|---|
| iPhone 網頁語音必須由「使用者點擊」啟動 | 不能一打開就自動講話 | 用「開始」按鈕的那一下解鎖語音，之後整場可用 |
| 螢幕自動變暗、鎖定 | 計時與語音會暫停 | 訓練中呼叫瀏覽器的「螢幕常亮」功能（Screen Wake Lock）。從主畫面開啟的版本需要 **iOS 18.4 以上**；切到別的 App 再回來時會自動重新開啟常亮；畫面上會顯示常亮有沒有成功開啟 |
| 手動按電源鍵鎖定，或切到別的 App | 這段時間內語音不會講 | 回到 App 時依真實時間校正進度，不會算錯；這種情況下沒講的語音無法補 |
| iPhone 的中文語音音色依系統而定 | 聲音好不好聽我們無法控制 | 預設挑系統裡的台灣中文語音（zh-TW） |
| 靜音鍵是否會讓語音消失 | 待實機確認 | 實機測試後在使用說明註明 |
